# The Weather Change Cookbook

This cookbook is a collection of recipes for analysing and visualising weather and climate data. Each recipe is a self-contained analysis that demonstrates a specific technique or method for working with weather and climate data.

This is a project of the ARC Centre of Excellence for the Weather of the 21st Century. We research how Australia’s weather is being reshaped by climate change.

**Website:** <https://21centuryweather.github.io/Weather-Change-Cookbook/>

Every recipe is designed to be:

- **Self-contained:** one folder with the notebook with explanations and code, any helper scripts, and instructions on how to run it.
- **Reproducible:** each recipe comes with its environment file and instructions for getting its data from a public source.
- **Reusable:** you can download a recipe and run it on your own machine.

## Accessing the recipes

### Read them on the website

Browse all recipes at <https://21centuryweather.github.io/Weather-Change-Cookbook/>.

### Download a recipe

Each recipe page has a download button in the page toolbar. It gives you a zip file containing the notebook, its helper scripts, and its environment file (`environment.yml` or `requirements.txt`). The data is not included, and the notebook does not download it for you, so you need to create the environment and get the data before running it. You will find a README.md file in the recipe folder with instructions on how to do that.

### Run it online with Binder

Some recipes have a **Launch on Binder** button on their page, which opens the notebook in a ready-made environment in your browser, with nothing to install. You still need to download the data before running the notebook, and the instructions are in the recipe's README.md file.
