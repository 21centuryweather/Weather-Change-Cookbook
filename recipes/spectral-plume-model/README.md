# README.md

Recipe title: The spectrum plume model for the relationship between convection and the large-scale environment

Authors: Dongqi Lin and Martin Singh

## Instructions to use this recipe locally

Before running the notebook locally you will need to make sure `scipy==1.16.2`, or create a Python environment following the steps below

* Python dependencies:

```bash
conda env create -f environment.yml
conda activate spm
```
* Data:

The cookbook notebook will generate data. There is no need to download data.

The notebook will create a `Data/` folder with the necessary data to run the notebook.

* Run the recipe:

Now you have all the components of the recipe. When running the recipe, make sure that the `spectral-plume-model/` folder is the working directory, by opening that folder in your preferred Python GUI.


## Instructions to use this recipe on mybinder

To run this notebook on mybinder, click the binder badge. This will open a new browser window with a Jupyter notebook interface where you can run the code without installing the environment locally. 

When using this option, take into account that mybinder resources are limited and the notebook may take a long time to run.
